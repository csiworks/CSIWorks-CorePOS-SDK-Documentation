LineItemBuilder

class LineItemBuilder

Builder class for creating and modifying LineItem objects in the CorePOS SDK. Provides a fluent API for constructing LineItem instances with proper validation.

val lineItem = LineItemBuilder.create()
    .setName("Espresso")
    .setItemId(itemId)
    .setQuantity(2.0)
    .setUnitCash(350L)   // $3.50 in cents
    .setUnitCard(365L)
    .build()

Use buildOrNull instead of build to get null rather than an exception when the configured state is invalid.
