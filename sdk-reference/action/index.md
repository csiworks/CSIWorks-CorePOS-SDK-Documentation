# com.coreposnow.sdk.action

| Type | Description |
|---|---|
| [Action](action.md) | Represents a custom action button that appears on the CorePOS home screen (landscape) and cart screen (portrait) top bar. Custom actions allow 3rd-party applications to be launched directly from the CorePOS UI. |
